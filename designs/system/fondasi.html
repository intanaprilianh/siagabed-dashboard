SiagaBed · Design system

Dikunci dari layar C″ (Ronde 3). Gaya kaca, Inter, mode terang dan gelap. Diam saat aman, sangat jelas saat ada yang salah. Status tidak pernah dibedakan dengan warna saja: selalu ada kata, ikon, dan bentuk.

Aturan status

Urutan prioritas sama dengan antrean. Kritis merah penuh dan Pra-alarm merah bening adalah keputusan pengguna (Ronde 2); Code Blue dibedakan lewat merah tua, bingkai putih, dan kata kapital.

Aturan pakai

Lakukan

  • Bed dulu, baru pasien: "301-B · Ny. R.W."
  • Selalu tulis alasan dalam bahasa perawat, dengan satuan dan jam 24 jam.
  • Tunjukkan status kiriman: mengirim → diterima hub → gagal.
  • Pakai tile lega untuk ≤ 8 bed, tile rapat untuk 24 bed atau layar 1366.

Jangan

  • Membedakan status hanya dengan warna.
  • Menaruh gangguan teknis di atas alarm klinis.
  • Menggeser item yang sedang disentuh.
  • Memakai merah penuh untuk hal selain Kritis, Code Blue, dan tombol Panggil Code Blue.
  • Memakai ungu demo di luar mode demo; ungu hanya berarti data fiktif.
